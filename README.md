# Sudha's website

Opens blank white → your line types itself out → the main site fades in:
a black header with one quote, two blocks of sliding photos/quotes, and
a link to a separate pink "letter" page.

## Files you'll actually edit
- `photos.js` — list your photo file names (put the real files in `photos/`)
- `quotes.js` — `HEADER_QUOTE` (the one in the black header) + `QUOTES` (used in the sliding blocks, 2 per block)
- `letter.js` — the letter title, body text, and signature on the pink page
- `music.js` — the file name of your background music (put the real file in `music/`)
- `script.js` — top of the file has `INTRO_TEXT`, the line that gets typed out first

## Files that just make it work (you shouldn't need to touch these)
- `index.html` — main page structure
- `letter.html` — the separate letter page
- `style.css` — every color/font/animation (color variables are at the very top if you ever want to retheme)

## Run it locally
Double-click `index.html`. Works fully offline, no installs.
